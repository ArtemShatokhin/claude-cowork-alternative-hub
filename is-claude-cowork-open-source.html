Is Claude Cowork open source?

No. Claude Cowork ships inside Anthropic's closed Claude desktop app. You cannot read its source, audit what it does with your files, run it on your own infrastructure, or point it at a non-Anthropic model.

Which alternatives are actually open?

OpenWork (MIT) and OpenHands (MIT) are OSI-approved open source. Kortix/Suna is source-available under the Elastic License 2.0 — the source is public, but commercial hosted-service use is restricted. Both differ from Claude Cowork in the same way: you can see and run the code. See the comparison table for the licence next to every option.
